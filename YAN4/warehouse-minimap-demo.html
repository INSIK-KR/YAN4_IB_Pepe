창고 미니맵 (레이아웃 JSON + 상태 데이터)

아래 레이아웃으로 랙·통로를 정의하고, 상태 객체에 빈 ID별로 empty | low | mid | high | full | block | ok를 넣으면 색이 반영됩니다. 실제 창고 도면에 맞추려면 구역(zones)을 나누고 랙(racks)마다 bins 개수와 aisleAfter로 통로 폭을 조정하면 됩니다.

① 레이아웃 JSON

통로는 aisleAfter: true 또는 "wide" 로 표시. 빈 ID는 zoneId-rackId-b인덱스 (1부터).

② 상태 데이터 JSON

키 예: "A-R01-12" → "high". 없는 빈은 기본색(empty) 처리.
