# CFS ATSOOS

CFS HTP, CFS IB LIVE와 별개인 Electron 앱입니다. 현재는 WMS 로그인까지만 구현되어 있습니다.

## 실행

```bash
npm install
npm start
```

휴대용 exe는 `npm run dist`로 `release` 폴더에 만들어집니다. 이때 `.dist-pack`에 복사한 코드를 난독화해서 넣으며, 원본 코드와 `npm start`에는 영향이 없습니다.

## WMS 로그인

- 로그인 창에서 `https://inbound.coupang.com/`을 열어 사용자가 직접 로그인합니다.
- 쿠키는 전용 세션 `persist:cfs-atsoos`에 저장되어 앱을 다시 켜도 유지되고, 다른 CFS 앱과 공유하지 않습니다.
- 로그인 여부는 쿠키 개수가 아니라 WMS에 실제로 요청해서 판단합니다. 로그인 화면으로 넘어가면 로그아웃 상태입니다.
- 앱을 켤 때, 로그인 창을 닫을 때, 메인 창으로 돌아올 때마다 다시 확인합니다.
- WMS 요청에는 시간 제한을 두지 않습니다.
- 센터 전환은 `/auth/changeCenter/{id}`를 호출한 뒤 첫 화면의 `centerId`로 실제 전환 여부를 다시 확인합니다. 이 앱의 세션만 바뀝니다.

## 엑셀 다운로드

- 데이터 화면과 개요 화면의 **엑셀 다운로드** 버튼으로 `취합 데이터`, `OOS 사유 근거` 두 시트를 다운로드 폴더에 저장합니다.
- 화면 표는 100행씩 나눠 보여주지만, 파일에는 항상 전체 행이 들어갑니다.

## 개요 화면

- 데이터와 WMS 재조회 결과로 지연 구간, 센터별 OOS, 출고 커트라인별, RCA_Level_3, F3/SD, From FC, 온도대를 유닛 기준으로 집계합니다.
- 지연 판정은 출고 커트라인과 상차, 하차, 진열완료 시간을 순서대로 비교해 처음 늦어진 단계로 정합니다. 커트라인이 여러 개면 가장 늦은 값을 기준으로 합니다.
- 센터별 OOS는 선택한 센터의 OOS 중 비중이며, 출고량 대비 비율이 아닙니다.

## 이관 정보 조회

- `cartbarcode`의 GC로 이관현황(`/transfer/admin/operation/paging`, 없으면 `same-center/paging`)을 조회해 상차, 하차, 진열완료 시간과 차량번호를 가져옵니다. 조회 조건은 CFS IB LIVE의 ATS 화면과 같습니다.
- GC는 재사용되므로 `ctbarcode`와 컨테이너가 일치하는 줄을 우선합니다. 일치하는 줄이 없으면 GC만 맞는 첫 줄을 쓰고 "GC만 일치"로 집계합니다.

## 출고 커트라인 조회

- 받은 데이터의 `ordernumber`를 중복 없이 모아 하나씩 조회합니다.
- 오더 상세 주소에는 주문 ID가 쓰이므로, 먼저 `/v2/orderPool/outbound/list`를 `orderNumber`로 검색해 결과 링크에서 주문 ID를 얻습니다. 기간은 OOS일~다음 날이고, 없으면 하루 앞까지 넓혀 다시 찾습니다.
- 데이터의 센터와 WMS 현재 센터가 다르면 먼저 WMS 센터를 전환합니다.
- 페이지에 고객 정보가 있을 수 있어 HTML은 메인 프로세스(`wms-order.js`)에서만 읽고, 화면에는 커트라인 값만 넘깁니다.
- 한 오더에 운송장이 여러 개이고 커트라인이 다르면 ` / `로 이어서 표시합니다.

## Power BI ATS OOS 받기

- 리포트 "ATS OOS dashboard_v1"의 데이터 내보내기 요청(`/export/xlsx`)을 앱에서 그대로 보냅니다.
- `powerbi-query.json`은 캡처한 요청 본문입니다. 리포트의 열이나 필터가 바뀌면 새로 캡처해서 이 파일을 교체합니다.
- 앱은 `centercode`, `oos_date`, `Month` 필터만 바꿔서 보냅니다.
- 체크박스로 고른 센터들을 한 번의 내보내기로 받습니다.
- WMS 재조회는 데이터에 나온 센터 순서대로 센터를 전환한 뒤 그 센터의 오더와 GC를 모두 조회하고 다음 센터로 넘어갑니다. 전환에 실패한 센터는 표시만 하고 나머지는 계속 조회합니다.
- 인증 토큰은 앱이 열어 둔 Power BI 창의 요청에서 얻고, 메모리에만 둡니다. 파일에 저장하지 않고 화면 코드에도 넘기지 않습니다.
