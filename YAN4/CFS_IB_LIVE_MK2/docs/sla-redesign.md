# SLA 화면 개편 (MK2)

## 목표
SLA 화면을 shadcn UI 분위기로 바꾸고, 중요한 지표를 위로 뽑는다. 수량은 지금처럼 피벗 표로 본다. 사용자가 시안 2안을 승인했다 (2026-11-01).

## 구성
- 맨 위 탭: 개요 / 피벗 표 / 이동중. 기본은 개요.
- 개요: 지표 카드 5개(총 미진열, MISS 누적, SLA 임박, 하차 진척율, 매입 진척율), 마감 시점별 막대, 지금 확인할 것, 기존 진척율 패널.
- 피벗 표: 행·열과 더블클릭 상세는 유지. 행 전체 색칠 대신 왼쪽 색 띠, 수량이 많을수록 진한 칸, MISS는 빨강. 이동중·임의상차·MISS 칸의 구분용 빗금은 유지.

## 원칙
- WMS 요청과 SLA 계산 코드는 고치지 않는다.
- 개요 숫자는 피벗이 그린 값에서만 만든다.
  - 총 미진열 = 피벗 총합계
  - MISS 누적 = 피벗에서 MISS로 표시된 칸의 합, 온도대별 표시
  - SLA 임박 = 피벗 칸을 만든 줄(SKU) 중 임박인 줄의 수량 합, 온도대별 표시 (기존 기준: TR·DIR 2시간, RocketMart·AG 8시간, MISS 칸 제외). 사용자가 '오늘 남은 마감' 대신 요청 (2026-11-01). 상세 패널의 실시간 반영은 칸 합계만 오므로 임박 수량은 칸 수량을 넘지 않게만 맞춘다.
  - 지금 확인할 것의 다음·집중 = 운영일(07:00~익일 06:59) 시간대 열 기준
  - 진척율 = 진척율 패널의 Total 값
- 원본과 비교하기 쉽도록 새 코드는 `src/yan4-sla-overview.js`, `src/yan4-sla-mk2.css`에 두고, `src/yan4-sla-page.js`에는 연결 코드만 넣는다.
- 캡처와 30min Auto는 탭과 상관없이 전체 영역을 찍는다. 찍는 동안 모든 탭을 잠깐 펼친다.
