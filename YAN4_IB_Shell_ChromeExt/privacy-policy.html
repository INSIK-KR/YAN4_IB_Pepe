YAN4 IB 통합 UI Shell (Chrome 확장 프로그램) 개인정보처리방침

시행일: 게시일 기준 최신 버전에 따릅니다. 문의: 스토어에 등록한 개발자 연락처를 이용해 주세요.

1. 총칙

본 확장 프로그램(이하 “확장”)은 Coupang 입고(inbound)·재고(inventory)·일부 출고(outbound) 업무 페이지에서 보조 패널을 제공합니다. 본 방침은 확장이 처리할 수 있는 정보의 범위와 보관 방식을 설명합니다.

2. 수집·처리하는 정보

확장은 다음과 같이 사용자 기기의 브라우저 안에서만 정보를 처리합니다.

  • 웹사이트 콘텐츠: 사용자가 방문 중인 Coupang 업무 페이지의 HTML·JSON 응답을 읽어, 발주·검품·SLA 등 업무 화면에 맞춰 패널에 표시하거나 정리합니다. 개발자가 운영하는 외부 서버로 해당 내용을 업로드·판매·제3자 제공하지 않습니다.
  • 로컬 저장(storage): chrome.storage.local에 패널 상태, 사용자가 지정한 보조 URL, 작업 진행 정보 등을 저장할 수 있습니다. 저장 데이터는 사용자 기기에만 남으며, 확장 개발자 서버로 전송되지 않습니다.
  • 클립보드(clipboardWrite): 사용자가 복사 버튼을 눌렀을 때에만 표·텍스트·HTML 등을 클립보드에 씁니다. 자동으로 클립보드를 읽거나 쓰지 않습니다.

3. 권한 및 접근 범위

확장은 매니페스트에 명시된 Coupang 도메인(inbound.coupang.com, inventory.coupang.com, outbound.coupang.com의 지정 경로)에서만 콘텐츠 스크립트가 동작하며, 동일 출처 요청을 통해 해당 사이트 데이터에 접근합니다. 그 외 사이트에는 접근하지 않습니다.

4. 제3자 제공·국외 이전

확장은 위 목적과 무관하게 정보를 제3자에게 판매·전송하지 않으며, 별도의 국외 이전 절차를 두지 않습니다. (단, 사용자 본인이 복사한 내용을 다른 앱에 붙여넣는 행위는 사용자 선택에 따른 것입니다.)

5. 보안

확장 패키지에 포함된 정적 스크립트만 실행하며, 원격에서 임의 코드를 불러와 실행하지 않습니다. Coupang 계정 로그인·비밀번호는 확장이 수집·저장하지 않습니다.

6. 변경

기능·권한이 변경되면 본 방침과 스토어 등록 정보를 함께 갱신합니다. 중요한 변경 시 스토어를 통해 안내 가능한 범위에서 공지합니다.

YAN4 IB Unified UI Shell — Privacy Policy (English)

Effective as of the date shown on the Chrome Web Store listing.

Summary

This extension adds a helper panel on specific Coupang inbound, inventory, and outbound pages. It may read page HTML/JSON from those pages only, to display operational summaries. Data is processed locally in your browser and is not uploaded to the developer’s servers. chrome.storage.local may store UI state and similar settings on your device. The clipboard is written only when you click a copy action. Host access is limited to the Coupang origins declared in the manifest. No remote code execution; only bundled scripts run.
