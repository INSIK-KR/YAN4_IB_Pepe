# CFS IB LIVE 앱 안 튜토리얼 설계

## 목적
처음 앱을 받은 사람이 PDF 가이드 없이도 앱 화면에서 바로 SLA·ATS 사용법을 익히게 한다.
게임 튜토리얼처럼 화면 요소를 강조하고, 캐릭터 말풍선으로 설명하고, 다음/이전/건너뛰기로 넘긴다.

## 범위
- 대상 앱: `YAN4/CFS_IB_LIVE`(MK1), `YAN4/CFS_IB_LIVE_MK2`(MK2). 둘 다 똑같이 넣는다.
- 투어 3개
  1. **기본 투어**: 상단 바 — 센터 확인·전환, WMS·PO·MOS·SHPT 로그인, `?` SOP, SLA·ATS 페이지 버튼, 튜토리얼 버튼
  2. **SLA 투어**: 직납완료 체크 → 기간 → 「SLA 전체」 → 진척율 → 피벗 MISS·시간대 칸 → 드릴·팀즈 → 직납 → 이동중
  3. **ATS 투어**: 「시간대 조회」 → 시간대 체크 → 「조회실행」 → 구간별 목록·행 색 → 팀즈/PDF 모드 → 보충마감 칩
- 문구: `CFS IB LIVE 사용 가이드.pdf` 문장을 바탕으로 짧은 다나까체.

## 열기 방식 (사용자 결정)
- **자동으로 띄우지 않는다.** 상단 `?` 옆 「튜토리얼」 버튼으로만 연다.
- 버튼을 누르면 작은 메뉴: 기본 / SLA / ATS. 투어를 고르면 필요한 페이지(SLA·ATS)로 먼저 전환한다.

## 캐릭터 (사용자 결정)
- 앱 아이콘(`build/icon.png`)의 개구리 택배기사를 원형으로 잘라 말풍선 왼쪽에 둔다.

## 동작
- 강조 대상 바깥은 어둡게, 대상은 테두리로 강조. 말풍선은 대상 옆(공간 없으면 위/아래)에 둔다.
- 대상 요소가 없거나 안 보이면(예: 조회 전 결과 칸) 그 단계는 화면 가운데 말풍선으로 설명만 한다.
- 버튼: 건너뛰기 · 이전 · 다음(마지막은 「완료」). 키보드 ←/→/Esc.
- 오버레이 z-index는 셸(2147483646)보다 위(2147483647).
- 창 크기가 바뀌면 위치를 다시 잡는다.

## 1~4 페이지 (사용자 결정: 카드마다 튜토리얼)
- 1·2페이지: 카드 헤더마다 작은 튜토리얼 버튼(🐸)을 둔다. 누르면 그 카드 안 요소만 짚는 짧은 투어.
  - 1페이지: Direct Tracking · Direct SLA · 가용화내역조회 · Prepack&SR Daily Patrol · STOW Error Tracking · Gross HTP · Need help Tracking
  - 2페이지: 입고내역 RWA · STOW SCAN TRACKING · RCRT QR 출력 · 수박비표 출력 · 바코드 생성 (빈 칸 「—」은 제외)
  - 테스트 중 카드(IB 오류처리 · Tote-Move RCRT88 · Location CONSOL)는 튜토리얼을 두지 않는다 (사용자 결정, 개구리 버튼도 없음)
- 3·4페이지(전체 1면 화면)는 상단 「튜토리얼」 메뉴에 페이지 투어로 둔다.
- 상단 메뉴: 기본 / SLA / ATS / 3페이지 / 4페이지. 1·2페이지 항목은 "카드의 🐸 버튼을 누르세요" 안내 투어.

## 제외
- 완료 여부 저장(자동으로 안 띄우므로 필요 없음) — 내 판단

## 구현 메모 (빌더 몫)
- 튜토리얼 코드는 `src/`에 새 파일로 두고 vendor로 복사되게 한다. `renderer/vendor` 직접 수정 금지.
- MK2는 SLA 화면 구조가 다르므로 선택자를 MK2에 맞춘다.

## SLA · ATS 예시 모드 (사용자 결정: A안)
- 조회 결과가 화면에 없으면 예시 데이터로 실제 결과 화면을 그린다. 결과가 있으면 그 결과로 안내한다.
- 예시 데이터: 회사 PC에서 실제 「SLA 전체」 · ATS 「조회실행」 결과를 숨은 단축키(Ctrl+Alt+Shift+T)로 추출 → 압축 조각을 구글 문서로 옮김(메일 · 드라이브 · PowerShell 막힘) → 가명 처리(상품명 · 업체명 · 작업자 ID). CT · 차량 4자리 · 토트 · SKU는 드릴 조인 키라 유지 — 내 판단.
- 그리기는 앱의 실제 함수(renderProgressPanel · applyPivotBundle · applyMovingPanel, ATS renderAllDashboardPanels)를 그대로 씀. 끝나면 원래 화면으로 복원.
- 예시 중에는 SLA · ATS 요청 함수가 바로 거절(WMS 요청 없음). 시간 제한은 넣지 않음.
- 직접 해 보기 단계: 강조 칸만 눌리고 나머지는 막음, 성공하면 자동으로 다음 단계. SLA = MISS 칸 · 직납 칸 더블클릭, ATS = CT 현황판 → 줄 펼치기 → 대시보드.
